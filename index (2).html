HARDWARE SYSTEM — HOW IT WORKS

VIDEO WALKTHROUGH · 32 SEC

The supplied clip compares a simulated correct response with a fan-fault case.

01 · Sensor layer

Temperature and atmosphere readings are monitored by zone. A fire indicator is treated as an event signal that needs confirmation.

02 · Controller

The controller receives sensor states, checks the affected zone, and coordinates the response logic shown in the simulation.

03 · Isolation status

The clip illustrates a zone boundary and door-state change to represent separating the affected area from the rest of the cabin.

04 · Airflow / fan feedback

Fan status is monitored. The comparison highlights that a fan fault can make the simulated event trend worse than the intended response.

05 · Crew-independent reporting

If no astronaut is in the affected zone, the dashboard records the event, system states, and whether automatic monitoring reports a fault. It does not assume a human has acknowledged the alarm.
